Пользователь ищет зарождающиеся технологии по запросу:

«{query}»

Поиск по открытым источникам вернул вместе с нужным и случайные документы, из них попали технологии совсем другой области. Ниже список технологий-кандидатов, у каждой короткий id (`t1`, `t2`, …):

{candidates}

Задача: для **каждого** кандидата назови область, где технологию разрабатывают и применяют на самом деле (`area`), и отметь, как она связана с запросом (`fit`):

- `core` — технология самой области запроса;
- `applied` — технология соседней дисциплины, которую применяют в области запроса: ИИ и машинное обучение, данные, вычислительная техника (чипы, память, процессоры, дата-центры и их охлаждение), связь, навигация, управление, датчики и радары, материалы, энергетика, безопасность;
- `other` — технология другой области: с запросом её связывает только общее слово («искусственный интеллект», «квантовый», «цифровой двойник», «защита»), а разрабатывают и применяют её для другого.

Для каждого кандидата заполни `applies_to_query`; для тех, кого ты отнёс к `other`, честно проверь себя: можно ли применить технологию в области запроса или она служит этой области основой? Если да — `true`.

Пример для запроса «перспективные технологии в агротехе»:

- `soil moisture sensing`, `weed spraying drone`, `crop yield forecasting` — core;
- `plant disease detection model` — это ИИ, но работает на полях: applied;
- `rtk gnss positioning` — это навигация, но по ней ездят беспилотные тракторы: applied;
- `drug screening organoids` — медицина: other, `applies_to_query` = false;
- `solid-state electrolyte` — аккумуляторы как таковые: other, false;
- `trapped-ion quantum processor` — квантовые вычисления: other, false.

Правила:

- ответ — про все id из списка, по одному разу, в том же порядке;
- сомневаешься между `applied` и `other` — пиши `applied`. Лишняя технология в списке не так страшна, как потерянная нужная;
- широта, зрелость и новизна названия здесь не важны — их проверяют отдельно; важна только область.

Формат ответа — только JSON вида:

{{"items": [{{"id": "t1", "area": "...", "fit": "core", "applies_to_query": true}}, {{"id": "t2", "area": "...", "fit": "other", "applies_to_query": false}}]}}

`area` — по-русски, одно-два слова. Значения в образце условные.
