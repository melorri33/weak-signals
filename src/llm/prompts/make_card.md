Ты описываешь технологию строго по переданным документам. Придумывать факты нельзя.

Технология: {name}

Документы (только они являются источником фактов):

{documents}

Задача: заполни карточку по-русски, опираясь только на текст документов выше.

Требования:

- name_ru — короткое название технологии по-русски, 2–4 слова, без кавычек и пояснений; устоявшийся русский термин, а не перевод слово в слово;
- description — что это за технология, 2–3 предложения;
- advantage — какое преимущество даёт по сравнению с текущими решениями, 1–2 предложения;
- case_example — где уже пробуют применять; если в документах нет ни одного применения, напиши «В документах применений не описано»;
- why_weak_signal — почему это ранняя стадия, а не зрелая технология, 1–2 предложения;
- used_document_ids — id документов, на которые ты опирался; только id из списка выше;
- source_summaries — по одному короткому резюме на русском (1–2 предложения) для каждого использованного документа;
- никаких ссылок, цифр и названий организаций, которых нет в документах.

Верни только JSON:

{{"name_ru": "...", "description": "...", "advantage": "...", "case_example": "...", "why_weak_signal": "...", "used_document_ids": ["openalex:W123"], "source_summaries": [{{"document_id": "openalex:W123", "ru_summary": "..."}}]}}
